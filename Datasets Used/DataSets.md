Datasets Used
1. PaySim Dataset

Source: Kaggle

Purpose: Transaction Fraud Detection

Description:
PaySim is a synthetic mobile money transaction dataset generated from real-world financial transaction patterns. It contains millions of transactions and labels indicating whether a transaction is fraudulent or legitimate.

Key Features:

Transaction Type
Transaction Amount
Sender Account
Receiver Account
Account Balances
Fraud Label

Usage in VeriTrust AI:

Detect suspicious transactions
Identify account takeover attempts
Calculate transaction risk scores
Generate fraud alerts

Dataset Link:
https://www.kaggle.com/datasets/ealaxi/paysim1

2. Credit Card Fraud Detection Dataset

Source: Kaggle

Purpose: Fraud Classification and Risk Scoring

Description:
This dataset contains anonymized credit card transactions made by European cardholders. It includes both legitimate and fraudulent transactions and is widely used for fraud detection research.

Key Features:

Transaction Time
Transaction Amount
Anonymized Transaction Attributes (V1–V28)
Fraud Classification Label

Usage in VeriTrust AI:

Train fraud detection models
Predict fraud probability
Improve trust score calculation
Identify unusual transaction patterns

Dataset Link:
https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

3. Customer Shopping Trends Dataset

Source: Kaggle

Purpose: Behavioral Analytics and User Activity Modeling

Description:
This dataset contains customer behavioral information such as purchasing patterns, user activity trends, product preferences, and engagement behavior. It is used to model normal user behavior and identify deviations.

Key Features:

Customer Activity Patterns
User Preferences
Purchase Behavior
Session Trends
User Demographics

Usage in VeriTrust AI:

Build behavioral profiles
Detect behavioral anomalies
Identify suspicious user activities
Improve adaptive authentication decisions

Dataset Link:
https://www.kaggle.com/datasets/iamsouravbanerjee/customer-shopping-trends-dataset

Why These Datasets?

Together, these datasets enable VeriTrust AI to address:

✅ Account Takeover (ATO)

✅ Behavioral Anomalies

✅ Fraudulent Transactions

✅ Suspicious Account Recovery

✅ New Device Risk (simulated through device fingerprints)

✅ Insider Threat Scenarios (simulated through employee activity logs)

✅ Adaptive Risk-Based Authentication

This combination provides both transaction-level and behavior-level intelligence required for continuous identity trust evaluation in digital banking environments.
